## Title
Data analysis for Investigating the role of dendritic cells in Sjogren’s disease

## Description
This github page contains the code used for the analysis of single cell RNA and spatial transcriptomics data in the master intership of Thijmen Daas titled: Investigating the role of dendritic cells in Sjogren’s disease.

## Packages
For each analysis the used R packages are at the top of the page. R version 4.5.2 was used for all analyses.
